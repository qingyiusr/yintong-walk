# 巷仔內的光｜上傳與維護說明

和「義起走讀！」用同一套架構：網頁放在 GitHub Pages，照片透過 Google Apps Script 存進計畫的雲端硬碟。

## 檔案說明
- `index.html`：網頁本體（一般不用改）
- `data.js`：所有文字內容與設定（地點、座標、路線、介紹、上傳網址）
- `apps-script.gs`：照片上傳到 Google 雲端硬碟的程式（貼到 Google Apps Script 使用，不用放上 GitHub）
- `images/`：地點照片（選填，檔名用地點代號，例如 `s1.jpg`）

## 玩法：一張照片點亮一扇窗
- 地圖上每個地點是一間小房子，每間有 6 扇窗（`windows` 可調）。
- 同學在某個地點每上傳一張照片，那間房子就亮一扇窗；第一扇亮起時整間房子從深藍色換成粉彩色，6 扇窗都亮了就是「整間亮了」。
- 窗戶數是**全班一起累積**的：地圖每 30 秒更新一次全班的照片數。首頁和地圖上方有「全班已點亮 N / 42 扇窗」的進度條，目標是一起把整條巷子點亮。
- 每個地點有「找找看」提示（`tasks`），給同學拍照的靈感。
- 每人每個地點最多拍 2 張（`maxPhotos` 可調），全班總數不限，6 扇窗亮滿後還是可以繼續上傳。
- 照片上傳後不滿意，點照片就能「換一張」或「刪除」。換一張不會少一扇窗。

## 學生使用流程
1. 掃 QR Code 打開網站（請用 Safari 或 Chrome，不要用 LINE 開）
2. 填學號和姓名 → 出發
3. 進入「走讀地圖」：預設方向和 Google 地圖一樣（上方是北），黃色虛線是走讀路線，藍點是自己的位置（手機詢問位置時按「允許」）。地圖可以一指拖曳、兩指縮放、兩指轉動旋轉；右下角指北針按一下轉回北方朝上，下面的按鈕回到整張地圖
4. 點房子或下方的地點 → 看介紹、找找看提示 → 按「拍一張，亮一窗」
5. 「我的照片」可以看每張照片的上傳狀態，等待補傳的可以按「立刻補傳」；點照片可以換一張或刪除

沒有集章，學生不用走到定點才能拍照。

## 一、上傳到 GitHub 並開啟網站
1. 登入計畫的 GitHub 帳號，按右上角「+」→「New repository」。
2. Repository name 填 `yintong-walk`，選 **Public**，按「Create repository」。
3. 按「uploading an existing file」，把 `index.html`、`data.js`、`README.md` 和 `images` 資料夾拖進去，按「Commit changes」。
4. 到「Settings」→「Pages」→ Source 選「Deploy from a branch」，Branch 選 `main`、`/ (root)`，按「Save」。
5. 等 1～2 分鐘，網址是：`https://你的帳號.github.io/yintong-walk/`

## 二、照片上傳設定（Google 雲端硬碟）
**學生不需要 Google 帳號**，只有設定的人需要用計畫的帳號登入。

1. 用計畫的 Google 帳號，在雲端硬碟新增資料夾「巷仔內的光」。打開它，網址最後那串英數字就是資料夾 ID。
2. 打開 https://script.google.com →「新專案」，刪掉原本的內容，貼上 `apps-script.gs` 全部內容。
3. 把 `ROOT_FOLDER_ID` 換成步驟 1 的資料夾 ID。`KEY` 可以改成你們自己的暗號。
4. 上方函式選單選 `testSetup` → 按「執行」，第一次會要求授權，按允許。完成後資料夾裡會出現試算表「銀同巷弄紀錄」和「走讀照片」資料夾。
5. 右上角「部署」→「新增部署作業」→ 類型選「網頁應用程式」：執行身分選**我**，誰可以存取選**所有人**，按「部署」。
6. 複製「網頁應用程式網址」（結尾是 `/exec`），貼到 `data.js` 的 `uploadUrl: ""` 引號裡；`uploadKey` 要和步驟 3 的 `KEY` 一樣。
7. 用瀏覽器打開那個 `/exec` 網址，看到「上傳服務運作中」就成功了。

設定好之後：
- 照片自動整理成 `巷仔內的光 / 走讀照片 / S11201234_林小美 / 青年路巷口_1128-143015.jpg`
- 試算表「照片紀錄」每一列是一張照片：學號、姓名、地點、拍攝時間、雲端連結。
- 不適合的照片，在「隱藏」欄填「是」，就不會算進地圖上的窗戶數。
- 學生自己刪除或換掉的照片，「隱藏」欄會自動填「學生刪除」，雲端檔案移到垃圾桶（30 天內可以救回）。學生只能刪自己學號的照片。
- 修改 Apps Script 程式後要「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」。

## 四、更新內容（只改 data.js）
- **地點**：目前 7 個地點的名稱和座標是依照路線截圖估算的，請到現場或用 Google 地圖核對。座標取得方式：Google 地圖上對地點按右鍵，點第一行的數字就會複製。
- **路線** `route`、**道路** `streets`、**公園** `park`：也是估算值，核對後一併修改，地圖會自動依座標重畫。
- 介紹 `intro`、找找看 `tasks`：依實際內容填寫。
- 內容確認後，把 `status: "draft"` 改成 `"ok"`。

## 五、注意
- 照片縮圖和上傳狀態存在學生自己的手機瀏覽器裡，換手機或清除瀏覽紀錄會不見；已上傳到雲端硬碟的照片不受影響。請提醒學生不要用無痕模式。
- 學生照片只存在計畫的雲端資料夾，網站上不會公開任何人的照片，只顯示全班的張數。
- 免費的 GitHub Pages 需要 Public 儲存庫，`data.js` 裡的上傳網址和暗號別人看得到。活動結束後可以到 Apps Script「管理部署作業」把部署封存，停止收件。
